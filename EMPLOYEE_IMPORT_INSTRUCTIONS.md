# Employee Bulk Import Instructions

## 📋 Required Fields
- **name** - Full name of the employee
- **email** - Must end with @abrafleet.com for your organization
- **phoneNumber** - Contact number with country code (e.g., +91-9876543210)
- **companyName** - Organization name
- **department** - Department name
- **status** - Must be: Active, Inactive, or Pending

## 📋 Optional Fields
- **employeeId** - Employee ID (e.g., EMP001, EMP002)
- **designation** - Job title/position
- **alternativePhone** - Secondary contact number
- **emergencyContactName** - Emergency contact name
- **emergencyContactPhone** - Emergency contact number

## 📝 Important Notes
1. **Email Format**: All emails must end with @abrafleet.com
2. **Phone Format**: Include country code (e.g., +91-9876543210)
3. **Status Values**: Only use Active, Inactive, or Pending
4. **CSV Format**: Save as CSV file, not Excel format
5. **No Comments**: Don't add comment lines or extra headers

## 🚀 How to Use
1. Download the `employee_bulk_import_template_abrafleet.csv` file
2. Open in Excel or Google Sheets
3. Replace the sample data with your actual employees
4. Keep the header row exactly as is
5. Save as CSV format (not Excel)
6. Upload through the bulk import overlay

## ❌ Common Mistakes to Avoid
- Don't add comment lines starting with #
- Don't change the header column names
- Don't use Excel format (.xlsx) - use CSV only
- Don't leave required fields empty
- Don't use invalid status values
